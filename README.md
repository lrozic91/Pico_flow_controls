Static website (HTML/CSS/JS, no build step) in Croatian (`index.html`) and English (`en.html`).

## Objava na Cloudflare Pages / Deploying to Cloudflare Pages

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → `lrozic91/Pico_flow_controls`.
2. Framework preset: **None**, build command: prazno / empty, build output directory: `/`.
3. Svaki push na `main` automatski objavljuje novu verziju. / Every push to `main` deploys automatically.
